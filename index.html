DLeo Bug Detective

An evolving tool for selected website checks and readiness diagnostics, with findings written so people can review and investigate them.

🔎

Website checks

Checks selected HTTP security headers. It cannot find every security problem or guarantee a site is safe.

Selected checks

Responsible use

Only test websites you own or have permission to assess. DLeo is not a complete security audit, antivirus, firewall, VPN, or automatic Android protection. Verify findings independently and test changes safely.
