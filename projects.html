Featured project

DLeo Bug Detective

An evolving developer tool focused on selected website checks, configuration diagnostics, and findings that people can review.

Read the Bug Detective project notes →

Active project

What it aims to do

  • Run selected checks against a website.
  • Present findings in readable language.
  • Help developers identify items that deserve closer inspection.

Important limits

  • Selected checks are not a complete security audit.
  • A result does not guarantee that a website is safe or unsafe.
  • Findings should be independently verified before acting on them.

Development priorities

  • Improve diagnostic accuracy and handle edge cases.
  • Explain why each finding matters.
  • Keep reports clear about uncertainty and limitations.
Planned improvements

Responsible use

Only assess websites you own or have permission to test. This project is not antivirus, a firewall, a VPN, or automatic device protection.
